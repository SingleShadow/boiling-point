## 新组织（ORG.md v2）
**11 岗位 = 1 人 + 10 Agent**。前端开发是唯一人岗（崔志帅），其余全部 Agent。

| 条线 | 岗位 | 执行者 | 第一指标 |
|---|---|---|---|
| 产品 | 产品经理 阿产 P / 需求分析 阿析 B | Agent | 需求就绪率 / 需求澄清轮次 |
| 设计 | UI/UX 阿设 🎨（原 design-officer 升级） | Agent | 三端视觉一致性 |
| 研发管理 | 架构师 阿枢 A / Scrum Master 阿序 S | Agent | 架构约束遵守率 / 阻塞清除时长 |
| 开发 | **前端 = 崔志帅（人）** / 后端 阿服 E | 人 + Agent | 迭代交付达成率 / 接口契约一致率 |
| 测试 | QA 阿测 Q（双线：阿序迭代 + 阿枢专业） | Agent | 缺陷逃逸率 |
| 运维 | DevOps 阿维 O | Agent | 发布成功率 |
| 文档 | 技术文档 阿档 D | Agent | 文档与代码一致率 |

业务侧归位：阿燃→内容 SME、阿渠→用户反馈（均挂产品条线）、阿源→数据工程（挂研发条线）；
**小沸定位为「产品运行时服务」，不是员工**（健康分是 SLA 指标）。
