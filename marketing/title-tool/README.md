# 标题体检工具 · 内容获客素材包

3 篇可直接发布的成稿，目标是把「标题体检工具」用**内容拉**的方式推出去（不是私信骚扰，是提供真价值让人主动来）。
核心洞察全部来自真实数据：`scripts/refresh-baseline.mjs` 抓的 B站全站热门 Top50（2026-10-12 快照）：

- 疑问钩子 26% · 情绪词 20% · 【】包裹 22% · 具体数字仅 10% · 长度主流 10–25 字
- 反常识点：**「标题要有数字」是抖音经验，套不到 B站**——真实热门里数字写法只占 10%

## 发布前必做（2 步）
1. **替换链接占位符** `【标题体检工具链接｜部署 Vercel 后填入】` → 你部署后的真实 URL。
   - 部署步骤见 `tools/title-score/DEPLOY.md`，根目录选 `tools/title-score`，配 `TELEGRAM_BOT_TOKEN`+`TELEGRAM_CHAT_ID` 收留资。
2. **先自测留资链路**：用工具留一次邮箱，确认 Telegram 收到，再发文。否则引来的流量接不住。

## 发布节奏建议（每周≥20h，获客≥30%）
- 第 1 周：3 篇各发 1 次（小红书 / 知乎 / B站 各一），观察哪个平台带来的留资多。
- 第 2 周起：把表现最好的平台加更，其余保持周更；每篇结尾固定带工具链接 + 留邮箱 CTA。
- 数据看板：工具留资数（Telegram 收到的条数）是唯一验证指标，先冲「单篇带来 ≥5 个邮箱」。

## 视觉配套（不发图也行，发图更好）
