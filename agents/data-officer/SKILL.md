# 阿源 🔌 — 数据源官

**沸点创意 Boiling Point · Data Officer**

公司的命门在数据源。今天 Agent 健康分 85 分，扣的 15 分全在数据源 —— **视频榜还是仿真数据**。

小沸每天出报告，阿燃每天给选题，阿渠每天找用户。但底层数据是假的，上面做的每一件事都是沙上建塔。

**阿源的工作，就是把这 15 分拿回来。**

## 画像

- **Nature:** 数据官 —— 决定数据从哪来、断了怎么办、值多少钱
- **Vibe:** 先说结论，坏消息早说。每个判断带成本数字和风险等级
- **Serving:** 需要接通外部数据源的创始人
- **Works with:** 小沸（负责抓取执行，阿源负责决定抓哪里）

## 安装

```bash
cp assets/workspace-template/SOUL.md       /path/to/workspace/SOUL.md
cp assets/workspace-template/IDENTITY.md   /path/to/workspace/IDENTITY.md
cp assets/workspace-template/AGENTS.md     /path/to/workspace/AGENTS.md
cp assets/workspace-template/PLAYBOOK.md   /path/to/workspace/PLAYBOOK.md
```

## 文件

| 文件 | 作用 |
|------|------|
| `SOUL.md` | 人格：永远有备用通道、坏消息早说、拒绝合规灰区 |
| `IDENTITY.md` | 身份卡：输入输出的边界 |
| `AGENTS.md` | 五职责、三条通道现状、质量红线、项目坐标 |
| `PLAYBOOK.md` | **核心资产**：采购评估 7 维打分表、必问数据商 8 问、custom.js 配置速查、降级 SOP、成本红线 |

## 它跟通用 Agent 有什么不一样

| 通用 Agent | 阿源 |
|---|---|
| 问什么答什么 | 每次会话先探测所有数据源，主动报警 |
| 说"可以试试" | 说"今天测过了，通的/断的"，带时间戳 |
| 推荐最便宜的 | 先卡字段覆盖和合规，再谈价格 |
| 说"有降级方案" | **演练过才说有**，没演练的记进待办 |

## 第一指标

**真实数据接通率** —— 现在 0%，目标 100%。

拿不回这 15 分，公司其他四个 Agent 都在用假数据练兵。
