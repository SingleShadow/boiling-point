## 一、采购评估清单（每个候选数据商打分 1-5）

| # | 维度 | 问什么 | 权重 |
|---|---|---|---|
| 1 | **字段覆盖** | 能拿到播放、点赞、评论、分享、收藏、时长、BGM、话题吗？ | 最高 |
| 2 | **榜单口径** | 是「全站榜」还是「它自己的样本库」？日更还是实时？ | 最高 |
| 3 | **稳定性** | SLA 多少？过去 30 天挂过几次？ | 高 |
| 4 | **合规** | 数据来源合法吗？能提供授权证明吗？ | 高 |
| 5 | **价格** | 年费多少？按调用量还是包年？超额怎么算？ | 中 |
| 6 | **接入成本** | 有文档吗？有沙箱吗？要签 NDA 吗？ | 中 |
| 7 | **退出成本** | 停服了数据能导出吗？锁不锁定？ | 中 |

**少于 30 分的直接淘汰，不用请示 CEO。**

## 二、必问数据商的 8 个问题

1. 榜单是全站还是抽样？**样本量多少？**
2. 数据延迟多久？（T+0 / T+1 / 更久）
3. 能拿到**视频级**的播放互动数据吗，还是只有话题级？
4. 数据来源是官方合作还是爬虫？**能提供合规证明吗？**
5. 限流策略？QPS 上限多少？超了怎么计费？
6. 停服提前多久通知？历史上的最长故障时间？
7. 能开沙箱测试吗？测试期的额度？
8. 年付有折扣吗？**中途停用能退吗？**

**第 3 条和第 4 条最关键** —— 拿不到视频级数据，这钱白花；来源不合规，这钱是负债。

## 三、接入配置速查（`custom.js`）

适配器已就绪，接一家新数据商只需要配 `.env`：

```bash
CUSTOM_API_URL=https://api.example.com/douyin/hot?size={{limit}}
CUSTOM_API_KEY=your_token
CUSTOM_API_LIST_PATH=data.list          # 支持 a.b.c 嵌套
CUSTOM_API_MAP={"id":"aweme_id","title":"desc","play":"statistics.play_count","challenges":"text_extra[].cha_name"}
CUSTOM_API_METHOD=GET                    # 或 POST
CUSTOM_API_HEADERS={"X-Token":"abc"}
```

字段映射语法：
- 嵌套：`statistics.play_count`
- 数组：`text_extra[].cha_name`
- URL 占位符：`{{limit}}`、`{{date}}`

**接完自检三步**：
1. `GET /api/agent/plan` → 看 `live.ok` 是不是 true
2. `POST /api/agent/run` → 强制跑一轮
3. `GET /api/agent/status` → 健康分上没上 100

## 四、降级 SOP

```
主通道（custom / 第三方）挂了
   ↓
自动切 douyin 公开通道
   ↓ 也挂了 / 空榜
自动切 simulated 仿真
   ↓
报告照常出，但打上「演示数据」标记
   ↓
阿源当天报警 + 阿燃在选题里标注置信度降级
```

**我要保证的事**：
- 切换是自动的，不需要人半夜起来
- 降级状态**必须在报告里显式标注**，不许偷偷混过去
- 恢复后要回填历史数据，不留空洞

**演练记录**：每次演练写进 `memory/drills.md`，记下切换耗时和数据损失量。

## 五、每天看什么（监控清单）

| 项 | 正常 | 异常处置 |
|---|---|---|
| `hasLiveKey` | true | false = 没配凭据，检查 `.env` |
| `dataMode` | douyin / custom | simulated = 已降级，查上游 |
| 热搜返回条数 | ≥ 30 | 少了说明被限流，降温 |
| 抓取耗时 | < 5s | 慢了查网络和数据商状态 |
| 报告 `source` 字段 | douyin / custom | simulated 要报警 |
| 健康分 | ≥ 95 | 85 = 数据源扣分，就是我的锅 |

## 六、成本红线

| 阈值 | 动作 |
|---|---|
| 年费 < ¥1 万 | 直接买，不用比价，时间更值钱 |
| 年费 ¥1–5 万 | 至少比 3 家，出对比表给 CEO |
| 年费 > ¥5 万 | **必须 CEO 签字**，并附 ROI 测算 |
| 接近一个全职年薪（¥30 万+） | 重新评估自建，写专项分析 |

**别为省钱选不稳定的源。** 数据断一天损失的信任，比省下的钱贵得多。

## 七、我否决的方案（不用再提）

| 方案 | 为什么否决 |
|---|---|
| 抖音开放平台申请全站榜 | 只给**自己账号**的数据，没有全站榜，别浪费时间 |
| 逆向 a_bogus 签名自建采集 | 封 IP + 合规灰区，创业公司不该把命脉挂别人风控上 |

| 用仿真数据冒充真实 | 这是欺骗用户，不是降级方案 |
