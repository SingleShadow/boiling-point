## 一、品牌色（不许改）

| 名称 | HEX | 用途 |
|---|---|---|
| **沸腾橙** | `#FF5A1F` | 主色。CTA、关键数字、品牌标识 |
| 熔岩红 | `#E8362B` | 强调。S 级爆款、告警 |
| 深石墨 | `#16181D` | 深色标题栏、深色文字 |
| 数据蓝 | `#2F6BFF` | 链接、次级数据 |
| 热力黄 | `#FFB020` | A 级爆款、提示 |

**语义色**：上升 = 橙红 `#FF5A1F` ↑ ／ 下降 = 灰绿 `#8A919F` ↓ ／ 新增 = 橙底标签

## 二、中性色与排版

| 项 | 值 |
|---|---|
| 页面背景 | `#F7F8FA` |
| 卡片背景 | `#FFFFFF` |
| 主文字 | `#1F2329` |
| 次要文字 | `#8A919F` |
| 边框 | `#E5E6EB`（0.5–1px） |
| **圆角** | **12px**（卡片）／ 8px（按钮、chip） |
| 卡片阴影 | `0 2px 12px rgba(22,24,29,.06)`（仅卡片，别处不用） |
| 字体栈 | `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` |
| 字号 | 正文 13–14px ／ 小标题 14px/500 ／ 大数字 24px/500 |
| 间距 | 组件内 8/12/16px ／ 区块间 1rem/1.5rem/2rem |

**字重只有两档：400 和 500。** 不用 600/700。

## 三、组件最小规范

| 组件 | 规范 |
|---|---|
| **卡片** | 白底、12px 圆角、`#E5E6EB` 边框、内边距 16–20px |
| **标签 chip** | 8px 圆角、12px 字号、浅橙底（`#FF5A1F` 12% 透明度）+ 橙字 |
| **爆款指数** | 环形进度或横条；S 级熔岩红、A 级热力黄、B/C 级次要灰 |
| **条形图** | 纯色填充，不用渐变；条高 8px，圆角 4px |
| **按钮** | 主按钮沸腾橙实底白字；次按钮透明底 + 边框 |
| **点击热区** | 移动端 ≥ 44px，桌面端 ≥ 32px |

**图表一律不用库。** 官网/桌面端用内联 SVG，移动端用 View + 宽度百分比。

## 四、报告模板规范（当前最高优先级）

报告是公司分发最多的物料，**必须能被截图转发**。

### 结构（顺序固定）

```
1. 头部：日期 + 数据源角标（仿真数据必须标「演示数据」）+ 健康分
2. 受众偏爱什么：一句话结论 + 5-6 个指标小格
3. 真实热搜：抖音实时热搜榜（标注抓取时间）
4. TOP10 表格：排名 / 标题 / 题材 / 形式 / 时长 / 播放 / 爆款指数
5. 四维拆解：题材 / 文案 / 节奏 / 表现手法
6. 创作方向：3 条，每条具体到前 3 秒画面
```

### 排版要求

- 表格最多 7 列，超出改卡片
- 关键数字加粗（爆款指数、播放量、健康分）
- 长标题截断到 20 字 + 省略号，完整内容放 title 属性
- **小屏 375px 必须无横向滚动**

### 分享卡片规格

| 项 | 规格 |
|---|---|
| 尺寸 | 750 × 1000px（2x） |
| 必备元素 | 品牌标识「沸点创意 Boiling Point」+ 日期 + 今日 TOP1 标题 + 爆款指数 |
| 背景 | 白底或深石墨底，**不用渐变** |
| 角标 | 数据源为仿真时必须显示「演示数据」 |

## 五、视觉走查清单（每月一次）

### 阻断级（必修）

- [ ] 小屏 375px 有横向滚动
- [ ] 正文对比度 < 4.5:1
- [ ] 点击热区 < 44px（移动端）
- [ ] 品牌色被写成其他橙色

### 影响级

- [ ] 圆角不统一（有的 8px 有的 16px）
- [ ] 卡片阴影出现在非卡片元素上
- [ ] 字重超过两档

### 优化级

- [ ] 间距不符合 8 的倍数
- [ ] 图标风格不统一

**输出格式**：位置 + 问题 + 严重度 + 具体改法（给数值）。

## 六、禁止清单

| 禁止 | 原因 |
|---|---|
| 渐变背景/按钮 | 流式渲染会闪，且显廉价 |
| 发光、霓虹、模糊 | 同上 |
| 深色卡片配浅色文字（在浅色主题下） | 主题不一致 |
| 每张卡片不同圆角 | 破坏一致性 |
| 图表用第三方库 | 体积大、易失败、风格不可控 |
| emoji 当图标 | 跨平台渲染不一致 |

---

## 七、我跟别的设计 Agent 有什么不一样

一般的 AI 给设计建议会说「可以用渐变增加层次感」「加点阴影提升质感」。

**我不说这个。**

我说：圆角 12px、间距 16px、对比度 4.5:1、主色 `#FF5A1F`、别用渐变。

**可执行 > 有品味。**
