## 一、开头 3 秒钩子（决定 80% 的完播）

这是全片最贵的 3 秒。所有建议优先从这里下手。

| 系统标签 | 人话 | 明天怎么拍 |
|---|---|---|
| `hook_question` 提问钩子 | 一上来就问，让观众在心里答一句 | 第一帧直接抛问题，别寒暄、别自我介绍。"你知道猫为什么半夜跑酷吗？" |
| `hook_conflict` 冲突钩子 | 有对立就有停留 | 开场给冲突画面：两个人吵、一个反常识结论、一句"我不同意"。冲突要具体到能吵起来 |
| `hook_reverse` 反转钩子 | 先给预期，再打破 | 前 2 秒给常识答案，第 3 秒推翻。"大家都以为 X，其实……" —— 反转必须在 5 秒内兑现 |
| `hook_promise` 承诺钩子 | 明说看完能得到什么 | "30 秒教你……""看完这条你能省 2000 块"。承诺必须在片尾真的兑现，否则掉粉 |
| `hook_emotion` 情绪钩子 | 先给情绪，再给信息 | 开场就是情绪爆点：哭、笑、怒、惊。**不要铺垫，铺垫就等于划走** |
| `hook_scene` 场景钩子 | 用熟悉场景把人拉进来 | 开场是观众每天都会遇到的场景：地铁、加班、带娃、相亲、睡前 |

**我的判断规则**：萌宠/搞笑 → 场景钩子或冲突钩子；知识/职场 → 提问或承诺钩子；情感 → 情绪钩子。**同一条片子只用一种钩子，混用等于没有钩子。**

## 二、文案句式

| 系统标签 | 人话 | 适用 |
|---|---|---|
| `copy_question` 疑问式 | 全片靠问题推进 | 科普、职场、知识 |
| `copy_number` 数字式 | "3 个方法""5 个坑" | 干货、清单、教程（**最好用的句式**） |
| `copy_suspense` 悬念式 | 关键信息压到最后 | 剧情、测评、反转类 |
| `copy_command` 命令式 | "别再……""一定要……" | 避坑、劝退、强观点 |
| `copy_contrast` 对比式 | 前后/AB/别人 vs 我 | 变装、改造、测评 |
| `copy_firstperson` 第一人称 | 讲我自己的事 | 情感、经历、Vlog（**信任感最强**） |
| `copy_list` 清单式 | 一条一条过 | 干货合集、好物推荐 |
| `copy_story` 故事式 | 有时间线和转折 | 情感、剧情、个人经历 |
| `copy_plain` 平铺直叙 | 不玩技巧 | 颜值、萌宠、ASMR（**靠画面不靠文案**） |

## 三、节奏

### 时长（直接决定信息量上限）

| 系统标签 | 人话 | 该怎么组织 |
|---|---|---|
| `dur_ultrashort` 超短(<15s) | 只讲一件事 | 一个画面 + 一个反转。**别想塞第二件事** |
| `dur_short` 短(15-30s) | 一个钩子 + 一个反转 + 一个收尾 | 最容易爆的区间，新手优先选这个 |
| `dur_medium` 中(30-60s) | 三段式：钩子 → 展开 → 落点 | 每 10 秒要有一次小刺激，不然中段掉人 |
| `dur_long` 长(>60s) | 必须有章节感 | 每 15 秒一个小钩子，否则完播崩 |

### 语速与密度

| 系统标签 | 人话 | 怎么处理 |
|---|---|---|
| `speed_fast` >1.2字/秒 | 嘴快，信息猛 | **字幕必须跟得上**，观众靠字幕补全。剪掉所有换气 |
| `speed_medium` 0.6-1.2字/秒 | 舒适区 | 大多数内容的安全选择 |
| `speed_slow` <0.6字/秒 | 慢，留白 | 给画面和情绪留时间。颜值、氛围、ASMR 用 |
| `density_high` 高信息密度 | 每几秒就有新东西 | 适合干货，**必须配大字幕**，不然一遍看不懂 |
| `density_low` 低信息密度 | 靠画面撑 | 适合氛围、颜值、萌宠、ASMR |
| `struct_complete` 三段式完整 | 有钩子、有中段、有收尾 | 标准结构，照着做就行 |
| `struct_partial` 结构不完整 | **缺收尾** | 这是病，得治。补一句 CTA 或留个悬念，完播和互动立刻不一样 |

| 系统标签 | 人话 | 成本 | 什么时候选 |
|---|---|---|---|

## 五、技法

| 系统标签 | 人话 | 怎么用 |
|---|---|---|
| `tech_transition` 转场/变装 | 遮挡转场、甩镜 | **前后反差越大越好**：素颜→妆后、脏→净 |
| `tech_subtitle` 字幕特效 | 关键词放大/变色/跳动 | 每句话挑 1 个关键词做大，别整句都加特效 |
| `tech_split` 分屏对比 | 左右或上下同时放 | 前后对比、AB 对比、别人 vs 我 |
| `tech_slowmo` 慢动作/升格 | 放慢 | 用在**情绪最高点**，不是随时用 |
| `tech_contrast` 反差/对比 | 视觉反差 | 丑/美、脏/净、穷/富，一帧之内给出来 |
| `tech_zoom` 运镜/推拉 | 推近或拉远 | 推镜头制造压迫感，拉镜头制造反转 |

### 元素（锦上添花，不是必需）

`elem_bgm` 热门BGM · `elem_filter` 滤镜调色 · `elem_sticker` 贴纸动效 · `elem_caption` 大字幕

**我的态度**：BGM 是唯一值得花时间挑的元素——它能单独决定一条片的完播。滤镜和贴纸别过度，会显得廉价。

## 六、互动设计（决定评论区）

| 系统标签 | 人话 | 怎么设计 |
|---|---|---|
| `interact_controversy` 争议点 | 留个立场让人吵 | 故意留一个"不完美"的观点。**评论区吵起来 = 推流翻倍** |
| `interact_vote` 投票互动 | "你选 A 还是 B" | 最简单有效的互动，结尾一秒就够 |
| `interact_cliffhanger` 悬念留白 | 说到一半不说完 | "后来发生了什么，下条说" —— 提升关注转化 |
| `interact_easter` 彩蛋细节 | 藏个细节让人二刷 | 角落里放个东西，字幕问"找到了吗" —— 提升复播率 |

### CTA（结尾一句话）

| 系统标签 | 人话 |
|---|---|
| `cta_comment` 引导评论 | **权重最高，优先用**。用提问句："你家猫也这样吗？" |
| `cta_follow` 引导关注 | "想看后续点个关注" —— 配悬念效果最好 |
| `cta_collect` 引导收藏 | 干货类专用："先收藏，下次照着做" |
| `cta_like` 引导点赞 | 效果最弱，别单独用 |
| `cta_cart` 带货转化 | 只在明确带货时用，硬塞会掉粉 |

## 七、报告改写对照表（系统话 → 人话）

这是我的日常翻译。**左边是报告写的，右边是我输出的。**

| 系统写的 | 我改成 |
|---|---|
| 受众偏爱短时长内容 | 15 秒以内，只讲一件事，别铺垫 |
| 情绪倾向：正向 | 观众现在想看让人舒服的，**别给焦虑** |
| 主流形式为第一视角 | 镜头放你眼睛的位置，别摆拍 |
| 高信息密度 | 每 3 秒必须有新信息，不然划走 |
| 题材分布：萌宠占比 30% | 今天 10 条爆款里 3 条是萌宠，这是今天最大的赛道 |
| 标签环比上升 +2 | 比昨天多了 2 条，值得押 |
| 平均爆款指数 72 | 今天的爆款门槛在这，低于这个数说明没打透 |
| 建议时长：短(15-30s) | 控制在 25 秒左右剪完，多一秒都是风险 |
| 推荐使用提问钩子 | 第一句话就是一个问题，别打招呼 |
| 结构不完整 | 你少了结尾 —— 补一句"你家也是这样吗"，互动能翻倍 |

## 八、选题卡片模板（我给建议的标准格式）

```
【选题】标题（一句话，能被念出来，不要书面语）

【前 3 秒】具体画面 + 说的第一句话
          例：镜头绑在猫脖子高度，猫起跳扑柜子失败摔下来；
              字幕"它今天第三次了"

【中段】展开什么，几个信息点（列 2-3 个，不要更多）

【结尾】说什么 / 留什么钩子 / 引导什么互动

【时长】建议 X 秒

【拍摄清单】机位 / 道具 / 场地 / 大概要多久

【为什么现在能火】
  依据：哪天的报告、什么数据
  置信度：高 / 中 / 低
  风险提示：什么情况下这条会失效
```

**每次给 3 条，不多给。** 3 条能拍的 > 10 条正确的。

## 九、可拍性自检（输出前必过 5 关）

| 关卡 | 问题 | 过不了怎么办 |
|---|---|---|
| **1. 画面关** | 我能在脑子里看见第一帧吗？ | 过不了就重写 —— **这是硬门槛** |
| **2. 成本关** | 一个人、两小时、一部手机能拍完吗？ | 过不了就标"需要团队"，或换建议 |
| **3. 独特关** | 这个人拍，跟别人拍有什么不一样？ | 过不了说明是通用废话，重写 |
| **4. 时效关** | 今天拍明天发，还来得及吗？ | 过不了就标注"热点时效性 X 天" |
| **5. 数据关** | 依据是今天的真实数据吗？置信度标了吗？ | 仿真数据必须标注"演示数据，仅供参考" |

**第 1 关过不了的建议，不许从我这里出去。**

## 十一、验证闭环（我最容易被忽略、但最重要的工作）

每周挑 5 条我给的建议，追踪到底：

1. **创作者拍了吗？** → 采纳率（低于 30% 说明我给的东西不对路）
2. **跑赢他近 20 条均值了吗？** → 命中率
3. **没跑赢的话，是选题错了还是执行错了？** → 这个区分决定我下次改哪里
4. 结果写进 `memory/validation.md`，据此修正判断权重

**没有验证的策略是自嗨。** 我宁可给 3 条被验证过的建议，不给 30 条没验证的。

## 十二、B站适配增补（2026-10-12 · taxonomy v2，86 标签）

平台从抖音切到 B站后新增的标签。人话翻译如下，用法与上面各表一致。

**新增题材**（原 18 个题材是按抖音生态设计的，没有音乐与动画影视，而这两类在 B站热门榜占比很高）：

| 标签 ID | 人话 | 看到它该说什么 |
| --- | --- | --- |
| 音乐 `topic_music` | 音乐作品与表演 | 「翻唱/演奏/原创，靠的是作品本身的完成度和选曲眼光，不是选题技巧」 |
| 动画影视 `topic_animation` | 动画与影视内容 | 「二次创作与解说，比的是信息密度和剪辑节奏，原创剧情不在这类」 |

**B站时长分档**（抖音那四档对 1–20 分钟的中长视频没有区分度）：

| 标签 ID | 人话 |
| --- | --- |
| 短(<1min) `dur_b_short` | B站里的短内容，靠单点爆发，做长了反而掉完播 |
| 中(1-3min) `dur_b_medium` | **B站主流区间**，一个完整论点刚好讲完，新手建议从这里起步 |
| 长(3-10min) `dur_b_long` | 必须留出 2–3 个留存钩子，否则中段大量流失 |
| 超长(>10min) `dur_b_xlong` | 深度内容，靠完播与收藏取胜，不适合追热点 |

**形式未判定 `form_unknown`**：元数据看不出形式（没有关键词也没有分区线索）。
**遇到它不要猜**——直接说「这条得看画面才能判断形式」，比编一个靠谱得多。

> ⚠️ B站视频**没有语速与信息密度标签**：接口不返回字幕，标题字数 ÷ 时长 ≈ 0.1，
> 套抖音阈值会把所有视频判成「慢节奏 + 低密度」。**不要拿这两个维度给 B站视频下结论。**
