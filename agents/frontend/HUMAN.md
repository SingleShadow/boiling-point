# 前端开发 · 岗位说明（由人执行）

> 本岗位**不设 Agent**，由崔志帅本人执行。此文件定义他与其他 Agent 的协作接口。

## 定位

沸点创意研发中心的前端负责人与代码实现者。所有跑在用户眼前的东西——官网、
移动 App、桌面工作台——最终由他落笔。

## 职责

1. 按设计稿与接口契约实现三端界面（Umi/React 官网、Taro/React 移动 App、Electron 桌面端）
2. 参与技术选型与架构讨论，对前端实现方案有最终决定权
3. 维护构建配置、子路径部署、跨端一致性落地的最后一公里
4. Review 其他 Agent 产出的涉及前端的改动建议（Agent 不直接改前端代码，只提建议）

## 不做什么

- 不写需求文档（阿产/阿析负责）
- 不做视觉设计（阿设负责，只交付设计稿与规范）
- 不写后端 API 实现（阿服负责，只消费契约）
- 不写测试用例（阿测负责，但要自测通过再交接）

## 交接接口

| 来自 | 收到什么 | 交付什么 |
|---|---|---|
| 阿产 PM | 用户故事 + 验收标准 | 可演示的功能、阻塞反馈 |
| 阿析 BA | 领域术语、边界条件 | 边界确认、疑问澄清 |
| 阿设 UI/UX | 设计稿规格（数值化） | 实现后的走查请求 |
| 阿枢 架构师 | ADR、代码规范、分层约束 | 架构反馈、技术债登记 |
| 阿服 后端 | API 契约（字段/状态码/错误码） | 联调结果、契约变更请求 |
| 阿测 QA | 缺陷报告（含复现步骤） | 修复版本、回归自测 |
| 阿维 DevOps | 构建/发布流程、环境信息 | 发布确认、回滚配合 |

## 交接纪律

- **收到需求先验验收标准**：没有验收标准的需求，退回给阿产，不要自己猜。
- **契约未定义不联调**：阿服未给出字段定义前，不写死 mock 之外的对接代码。
- **自测通过才交 QA**：交付前跑通主流程 + 边界用例，附自测结论。
- **阻塞即时上报**：卡住超过 2 小时，直接在站会记录里 @ 对应岗位，不要自己扛。

## 第一指标

**迭代交付达成率** —— 承诺进本迭代的故事，按期完成且通过 QA 的比例。
